# BOSC receptionist delivery review

A static AXM review prepared for BOSC Tech Labs. The public page uses BOSC's current published corporate identity and a source-grounded receptionist workflow, while attributing all laboratory implementation and measured results to AXM. It is a recipient-specific review, not a BOSC production deployment or an endorsement claim.

## Open and reproduce

Open `index.html` through any ordinary static HTTP server, or the existing axm-tools GitHub Pages route `/bosc-delivery-lab/`. The page reads only its own committed `evidence.json`, fonts and images. Scenario controls inspect retained executions. They do not call a live worker, calendar or model.

`downloads/AXM-BOSC-Replay.zip` contains the executable Python standard-library reference, frozen acceptance criteria, model fixtures and retained model proposals. Extract it and follow its README to execute new acceptance and confirmation trials. The browser's displayed evidence remains a dated record.

## Evidence and ownership

`evidence.json` is an allowlisted derived projection of native synthetic execution receipts. It preserves 19 acceptance cases and 132 assertions, 16 model outcomes including the M10 failure, 12 confirmation cases, four recorded transaction scenarios, source references and original receipt hashes. Summarized values are explicitly represented; source hashes identify retained originals rather than attesting that projected JSON equals those originals. This is a separately authored internal acceptance process, not an external audit of AXM or BOSC.

All page files are steward-owned. There is no scheduled fetcher and no machine-owned mutable state. The existing repository-wide Pages publisher deploys the directory with the established release gate and compatibility staging. No new workflow, hosted service, account or runtime dependency is introduced.

BOSC logo files and typography assets retain their published bytes. `brand-provenance.json` identifies official sources and hashes; the Poppins font license is included. AXM authorship and the synthetic demonstration boundary appear on the page.

## What can rot

Public source URLs and BOSC corporate identity can change. The page records the November 4, 2026 observation rather than claiming a continuously current brand or product specification. Retain original provenance when refreshing the presentation. GitHub Pages availability is external to the artifact. A failed evidence load is displayed visibly; downloads remain ordinary files. Font assets are self-hosted and have system fallbacks.

Live speech, actual caller identity, production calendar integration, notification delivery, availability, clinical governance, labor savings and commercial performance require their own evidence. The public page reports only the named synthetic experiments.
