Evidence before inference

Authenticate source ownership and preserve exact event bytes. The Python runner checks hashes and event IDs; findings remain hypotheses until corroborated. Uploads are never required.

Local AI, optional and bounded

The local model adapter supports only loopback inference, minimizes event context, rejects fabricated citations and never gains containment credentials. Nothing depends on it.

Recovery is part of response

Signed authority, containment effects, rollback criteria, communications and post-incident improvements belong to an organization's operational system. This desk exports review packets, not unapproved actions.
