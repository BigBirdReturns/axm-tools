What it does today

Search and compare the observed listings; inspect before/after titles; import a seller CSV; export review records; prepare a local inventory photo; replay the catalogue audit from retained inputs.

What stays with the seller

Physical inventory, actual-unit photography, prices, stock, commercial rights and final listing decisions. This build contains no eBay write integration and cannot change the live store.

THE UNDERCAST METHOD, ADAPTED

Every image is a claim.

Acquire the source once, retain its identity, review the exact subject, then prepare its display. A byte hash establishes which photograph was used; inspection establishes what it depicts. A listing reference never silently becomes an actual-unit condition photograph.
