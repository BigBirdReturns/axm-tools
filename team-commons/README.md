# MARY Team Commons 0.2.0

A self-contained browser lab for collective improvement at a demo day. `index.html`, `style.css`, `core.js` and `app.js` are the served source. No runtime network calls, packages, model inference or paid API are used. The offline HTML includes those exact sources. Public browser ZIPs contain only this application, synthetic contributions and instructions; the separately licensed MARY Portable core, estate files, credentials and personal data are excluded.

## Exercise

Three synthetic teams contribute inventory, maintenance and allocation evidence. The one-part calculation preserves missing quantities, source identities, correction history and contributor credit. A data-only mapping resolves one fresh synthetic field layout. Workspace restoration recomputes saved conclusions. This is not authentication, physical truth, tenant isolation, full assistant provisioning or field qualification. Public participation does not grant a sponsor or AXM authority over a competitor's private data.

## Verification

Run `node tests/verify.cjs` for the retained 22-case logic suite. `#selftest` on the page explicitly runs the browser exercise with synthetic file inputs and appends a machine-readable result. Ordinary visits run no automatic tests. External independent validation is not claimed.

## Design

Cream Editorial learning commons within a Dark Ecosystem station section. Olive and pine identify cooperative state; ember marks shortages and errors. The favicon is an original contribution-diagram icon, not the frozen SCG mark. System fallbacks preserve operation without font downloads. Reduced-motion and keyboard navigation are included.
