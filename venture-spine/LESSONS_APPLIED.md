# Lessons applied from the axm-tools estate

Venture Spine is deliberately assembled from the strongest mechanisms already proven across the estate rather than inventing another dashboard.

| Estate tool | Mechanism retained | Venture Spine application |
|---|---|---|
| Manzanita | One object, multiple genuine apertures; seats change action and evidence; public projection cannot create field authority | Claims, evidence, relationships, rights, decisions, and handoff are different projections over one cartridge; role views do not grant authority |
| Manzanita Works | Fundraising is a subordinate projection, not the institution; deep links, print, mobile, reduced motion | Capital is one record class inside the governance spine; route state is shareable and the page qualifies desktop/mobile/print/reduced motion |
| Essential Attention | One best next action; five ordinary places; local source hashing; effect firewall; cold replay; portable packet | Today, Records, Decisions, Intake, Handoff; draft-only decisions; local receipts; held external effects; successor replay |
| Clinical Site Fabric | Multi-file local intake; structured parsing; unsupported files retained hash-only; proof cannot become domain truth | JSON/NDJSON/CSV/TSV/text intake; no silent discard; technical evidence cannot become corporate authority or customer acceptance |
| Case Zero | Credential/PII holds; source-content-zero share packet; client/relationship authority boundary | Sensitive-pattern flags; public export strips filenames and private state; public Pelagos cartridge neither quotes nor relies on the private introduction thread |
| AXM Witness | Exact artifact digest; tamper detection; duplicate refusal; encrypted backup; interrupted import recovery; replacement lineage; live-readback discipline | Canonical SHA-256 cartridge/packet identity; AES-GCM private backup; import journal; duplicate and tamper refusal; successor lineage; cache-bypassed exact-byte live readback |
| Polybolos | Permanent bounded receipt; new tests cannot retrospectively regrade old work; explicit public/private source opt-in | Anti-goalpost law; corrections append or supersede; private source bytes never enter public export |
| Acceptance | One-file buyer-facing challenge; zero network; no production credentials or writeback | One-file public demonstration with synthetic intake and no external effects |
| Organ Evolution | Separate identity/function/implementation/supplier/authority; no total score; stress before decision; migration/succession | Separate company objects and actors; per-dimension stress results; no governance score; cold handoff and lineage |
| PTA Tracker | Fail loud or show partial source failure; hostile-source seam; gap detector; remove typing without removing interpretation; shared corpus reduces maintainer risk | Visible holds and stale state; `observed.json`; deterministic gap checks; templates automate record structure while named humans retain decisions |

## New combined floor

Venture Spine requires all of the following in one release:

- a public-safe cartridge with exact integrity identity;
- an offline one-file runtime and zero unexpected requests;
- one recommended action and progressive disclosure;
- local multi-file hashing and structured intake without source-byte retention;
- IndexedDB persistence with localStorage fallback;
- claim, evidence, authority, instrument, rights, decision, settlement, and correction separation;
- local draft decisions with rationale-bearing receipts;
- public/private packet classes and encrypted local backup;
- tamper detection, duplicate refusal, import recovery, and lineage;
- an external-effect firewall that can prepare but never execute;
- no single governance score;
- stress scenarios, cold-successor replay, print, mobile, 320 px at 200 percent text, keyboard operation, theme persistence, and reduced motion;
- stdlib validation, browser qualification, an exact release receipt, and an honest rot statement;
- cache-bypassed exact-byte GitHub Pages readback with a durable no-churn release receipt.

Pelagos is the first cartridge, not the hard-coded product boundary.
