# Civil Continuity — Suginami working case

This is an application of the existing estate's civil-resilience work, not a replacement architecture. It connects ordinary food distribution, infrastructure maintenance, shared community capacity, energy and communications constraints to a retained decision that survives the originating session.

The source owners remain distinct:

- Manzanita Works owns the existing institutional model: tools, time, talent, pilotage, money, mobility, knowledge and space; bounded authority and acceptance; replaceable vendor interfaces; practical manual fallbacks.
- Manzanita's public working model supplies the seven stages: Need, Evidence, Decision owner, Safe next step, Backup path, Outcome, Next improvement. This page carries an exact source-hashed projection of that contract, not an independently rewritten institution.
- Cantos ResearchCore owns the actual journal, revisions, reviews, dependencies and native packet. The exact owner source is unchanged.
- AXM Genesis owns one-pass compilation, canonicalization, Merkle construction, hybrid signatures, independent verification and amendment lineage. Its kernel is unchanged.
- These civil adapters own narrowly stated arithmetic, inventory-rights transitions and dependency interpretation. They never authenticate a municipal role, generate a physical observation or grant an external action.

The recovered food-web and civil-maintenance lineage motivates the everyday-to-outage relationship. This public release does not redistribute private counterpart messages, private investor material, operational military designs, resident records, credentials or signing secrets.

## What you can do

Open `index.html`. Run the connected exercise, or use a local source case.

**Shared capacity.** Inspect the resource owners and alternate service paths. Remove grid, internet, a hosted service, a supplier, radio or staff. Combine losses. Age the observations. Supply a different resource/dependency model. A fixed-point evaluation refuses self-supporting cycles that have no independently available source. Path availability is separated from usable quantity and actual delivery. Human staff and manual handoff remain explicit resources.

**Food web.** Retain stock, source dates, expiry, quality, quotas, route capacity and destination demand. A disconnected seat may reserve only its preassigned rights. Reservation, departure and recipient acknowledgment remain different states. Short or unknown arrival never returns spent stock to inventory. Late receipt is evidence and remains admissible after the dispatch lease ends. Exact duplicate operations deduplicate; conflicting writers from the same seat sequence hold. Reconciliation is a candidate, not an automatic stock rewrite.

**Everyday economics.** Compare one procurement volume with all declared purchase, transport, storage, paid labor, energy, maintenance, administration, capital and spoilage costs. Missing costs are refused. A coordination cost increase can reverse the apparent shared advantage. The sample is synthetic; it demonstrates the comparison, not competitive superiority over any actual retailer.

**Energy and water.** Recompute the entire declared load horizon, solar contribution, protected reserve, initial state of charge, conversion efficiency, inverter limit and dark interval. The hourly model uses a simplified six-hour solar-production window. The operator can explicitly apply a modeled shortfall to the local backup resource so a dependent service becomes held. Water quantity and pump-energy accounting remain separate from potability and physical infrastructure qualification.

**Messages.** Compare a compact state message with the actual serialized size of a retained packet snapshot. Account for nodes, rate, available channel fraction, forwarding and retries. The full local evidence record need not be transmitted for every short state update. This calculation establishes neither Japanese radio compliance nor RF coverage or delivery reliability.

**Keep and continue.** Export a native packet, a self-contained offline workbench or a handoff note. Another local session verifies journal and domain replay before import. A corrupted import preserves the current workspace. Optional browser persistence is explicit. Native Genesis sealing remains an additive custody operation, not a requirement to use the browser.

## Reproduce

The browser is self-contained. Native checks use Node 22+ and Python 3.12+. Native Genesis operations require the existing explicit kernel environment documented in `../README.md`.

```sh
node --test tests.cjs fabric.test.cjs
python build.py --check
node create.cjs /new/result/directory
node packet.cjs /new/result/directory/successor.json
python validate.py

# Installed axm-genesis, exact source reference inherited from the parent:
python native_test.py --out /new/genesis-test-directory
python seal.py consume /path/to/successor \
  --trusted-key /independently-held/publisher.pub \
  --predecessor /path/to/origin
```

`seal.py seal` requires an explicit private key, publisher metadata and timestamp. It calls the parent Genesis adapter after the municipal and civil records have replayed. It does not implement cryptography, change the kernel, edit a shard after signing or fall back to a default key. The packet carries the exact new consumer identity in its retained source basis. The consumer uses installed known code, never code or shell instructions imported from a packet.

The downloadable artifact pair uses a disposable fixture identity. Its private half is generated in memory by the kernel and discarded before cold consumption. The public key is a test trust anchor, not a claim of institutional authority. A separate physical-node receipt records W03 production and N01 consumption without the original session or secret.

## Scope of software acceptance

Tests cover stock conservation, concurrent rights, false receipts, late receipts, observation currency, lease expiry, failed imports, forged resource states, cyclic dependencies, loss of staff, complete cost, energy balance and cold continuation. Browser tests exercise the actual controls, files, offline restoration and narrow layouts. None is a field qualification of a town, battery, radio, supply agreement, health condition, institutional actor or military outcome.

The commodity counts here are packaged-meal units. Nutrition, allergies, cold-chain product rules, home-sheltering demand, water quality, sanitation, medical support, accessible transport, replenishment, concurrent service capacity and physical inspection require their own evidence and policies. Unknown values stay unknown. Actual service operations retain their existing owners.

## Source layout

`municipal.js` owns physical-unit arithmetic and bounded inventory transitions. `fabric.js` owns declared civil dependency paths, complete-cost comparison and water arithmetic. `assurance.js` records and independently recomputes those assessments through ResearchCore. `workflow.js` exposes the existing native-case workflow to the browser. `create.cjs` and `packet.cjs` produce and cold-consume native packets. `seal.py` composes the established Genesis adapter. `app.js` is presentation and explicit operator interaction. `build.py` produces the source-matched page and offline kit.
