# Rebuild and accept

Run `python -B scripts/build.py` from this directory to refresh the source inventory and deterministic distribution. Run `python -B -m unittest discover -s tests -v`, then `python -B proof.py qualify --output /private/new-run`. Re-run from the extracted ZIP on another host and compare source manifest identity and native verdicts. Dynamic times, temporary paths, random synthetic record IDs and private runtime receipts are observations, not byte-identical replay promises. The distribution ZIP is deterministic for identical source files.

Release publication uses an allowlisted summary, never raw partner correspondence, source vaults, credentials or host paths. A new donor is admitted only after its owning source, execution contract, report interpretation, negative controls and independent cold replay are explicit. The orchestration contract is versioned separately from the donor's native capsule schema.
