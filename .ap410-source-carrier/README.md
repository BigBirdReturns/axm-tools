# AXM Aperture AP-410 source carrier

This directory is an execution-only, never-merge transport for the checksum-bound AP-410 source candidate retained outside GitHub.

Six text shards reconstruct `AXM-Aperture-AP410-Source-Candidate-v1.tar.gz` exactly. The pull-request workflow verifies every shard, the concatenated base64 stream, the tracked-source archive, and the embedded AP-410 source archive and receipt ledgers before executing the full 868-contract denominator on Ubuntu 24.04 and Windows 2025. A dependent package job rebuilds the embedded deterministic source archive, cold-extracts it, repeats all 868 contracts, and retains a source-candidate receipt.

This carrier owns no AXM Aperture product, package, platform, reader, publication, AP-410, or G3 authority. It must close without merge after the artifact is independently verified.
