# Case Zero · Tier Desk × RedCat external qualification

A local-only workbench for testing Tier Desk against one real, failed client engagement without asking RedCat to upload the raw engagement record or trust a hosted runtime.

Public route:

```text
https://bigbirdreturns.github.io/axm-tools/case-zero/
```

## What the page does

The page is one self-contained HTML file. It can:

- accept a folder or selected files inside the browser;
- hash every selected file locally;
- classify surviving evidence by commercial, communication, delivery, technical, economics, acceptance, change, outcome, source-code, or unknown shape;
- count credential- and PII-shaped signals without retaining or exporting matched values;
- show which of ten Case Zero analysis jobs have enough source classes to begin and which remain held;
- export a body-free local manifest or a path-pseudonymized share-safe preview; and
- download a deterministic Python runner and a compact pre-read from bytes embedded in the page.

The synthetic example exercises the browser path before any client material is selected.

## What it does not do

The page makes no network requests. It does not upload source files, call a model, contact the historical client, interpret the engagement, calculate a counterfactual, or authorize a shadow pilot.

The browser stops at the evidence and execution floor. A substantive Case Zero result still requires source-addressed reconstruction, explicit missing and contradictory evidence, actual-versus-counterfactual economics, and RedCat architect challenge.

## Authority

RedCat retains the client relationship, pricing, commercial terms, brand, scope and delivery authority, disclosure decisions, and final disposition. Tier Desk may reconstruct, decompose, verify, and report. It may not contact or represent the historical client. Models and tools produce candidate analysis only.

## Operating paths

### Browser preview

Open `index.html`, select a folder or files, and choose **Build local preview**. The exports contain manifests, holds, coverage, and the proposed analysis queue. They contain no selected source-file contents.

### Deterministic local runner

Download `downloads/redcat_case_zero_runner_v0.1.zip`, download `casezero.py` from the page, or use the readable source under `runner/`:

```powershell
python casezero.py intake `
  --input "D:\RedCat\CaseZero\raw" `
  --output "D:\RedCat\CaseZero\intake" `
  --case-id "REDCAT-CZ-001" `
  --custody-mode "redcat_local" `
  --as-of "2026-09-01T12:00:00Z"
```

The runner uses only the Python standard library and makes no network calls.

## File ownership

There are no machine-owned client or case files in this tool.

- `index.html`, `README.md`, `runner/`, `scripts/`, `tests/`, and the workflow are steward-owned source.
- `QUALIFICATION.json` is deterministically generated by `tests/validate.py`.
- `downloads/` contains frozen v0.1 release objects generated from the readable source. A content change requires a new version and new identities.
- Browser-selected client material is never written into the repository.

## Qualification

```bash
python case-zero/scripts/build_release.py
python case-zero/scripts/integrate_root.py
python case-zero/tests/validate.py
node --check /tmp/case-zero-inline.js
python -m unittest discover -s case-zero/runner -p 'test_casezero.py' -v
python case-zero/tests/browser_test.py
```

The browser campaign serves the real route over loopback, refuses external requests, executes the synthetic case, tests the credential hold, downloads and inspects the runner, pre-read, local manifest, and share-safe packet, and checks mobile and 200-percent-text composition.

## What can rot

- `webkitdirectory`, drag-and-drop, clipboard, and Blob-download APIs may change.
- Browser download permissions may change.
- Content Security Policy support may change.
- GitHub Pages and workflow actions will eventually require mechanical upgrades.
- The filename classifier is a first-pass projection, not a semantic parser; ambiguity must remain visible.

The durable properties are local custody, body-free preview export, exact hashes, visible holds, ten bounded analysis jobs, RedCat ownership of the client relationship, and refusal to manufacture a conclusion from incomplete evidence.
