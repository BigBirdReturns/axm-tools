# Package boundary

The frozen `downloads/redcat_case_zero_runner_v0.1.zip` is generated from this readable directory by `case-zero/scripts/build_release.py`. It contains no client data, credentials, API configuration, model runtime, or network dependency.

The package qualifies deterministic intake only. It does not reconstruct the engagement, calculate a counterfactual, issue a commercial recommendation, or authorize a shadow pilot.
