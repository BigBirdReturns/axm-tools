# Danger Room / Shield AI · Simulation Director

A self-contained operating workbench prepared for Nacho Sanz-Pastor's international simulation leadership brief. It extends the existing [Danger Room](https://bigbirdreturns.github.io/axm-tools/danger-room/) and joins acquisition integration, account qualification, coverage, partners, product packaging, forecast review, engineering evidence, release decisions and customer handoff in one local workspace.

Published entry: https://bigbirdreturns.github.io/axm-tools/danger-room/shield-ai/

The initial cartridge contains clearly fictional commercial records, source-bound public context and separately labelled existing AXM research evidence. Its executable 2D quality experiment is a browser reference harness, not a claim of Aechelon or Hivemind integration. Agents authored the workbench; the published application executes deterministic local rules and contains no hidden model service.

## Use

Open `index.html`, choose **Run the working day**, inspect any function, change the fictional records, run the quality experiment, and export a current operating review or full workspace. The application preserves its local event history and supports file-based handoff. `standalone.html` embeds the complete application for local use.

The original Danger Room view replays the original native Fly-0 receipt and accepts the original camera CSV format. Danger School executes a fresh browser reference experiment, retains failed cases, evaluates a stated scope and rechecks accepted evidence on import and reload. The commercial records consume that exact accepted scope while maintaining separate buyer, budget, procurement and customer-acceptance conditions.

## Ownership and boundaries

All checked-in files are steward-owned. Browser workspaces remain local. Real company adoption requires named owners and real source records. The tool produces decisions, briefs and evidence for review; source-system connections and external communications are explicit integration work. No source material from private Shield AI systems is present.

node danger-room/shield-ai/tests/capture.test.js

The browser acceptance path covers the working day, scoped release, commercial acceptance, wider-scope rejection, saved-state revalidation and the original replay/capture intake. The enclosing axm-tools repository publishes its root with GitHub Pages. Preserve its release gate and sibling tools. `PROVENANCE.json` and `QUALIFICATION.json` record the source boundary and checks for this module.

## What can rot

Browser storage, Web Crypto, file downloads and GitHub Pages can change. Explicit export preserves the complete workspace independently of browser storage. Public role and product sources are dated observations; refresh them as source changes, without silently relabelling older evidence. The module has no runtime package dependencies, external font, analytics or paid service.

## Lineage

The primary source is the existing `danger-room/index.html`: its original receipt, samples and capture templates are preserved in `recorded.js`. The original page remains unchanged. The module extends its failure/replay/curriculum/evaluation mechanism into a complete operating function. It also follows the portable workbench delivery pattern used in `pelagos-governance/`, the Robi Sen collaboration. The fresh browser experiment and the estate evidence retain their separate identities.
