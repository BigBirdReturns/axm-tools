# Lineage and lessons carried forward

This release is a self-contained tool. It imports no code or runtime dependency from another AXM tool. It does, however, carry forward mechanisms that survived earlier work.

| Prior surface | Lesson retained | Pelagos implementation |
|---|---|---|
| Manzanita | Apertures are governed projections, not alternate truths; seats change available action; adverse-use boundaries must be explicit. | Internal, public, diligence, and counsel apertures over one immutable baseline; role profiles change emphasis without changing truth. |
| Manzanita Works | Fundraising and other dashboards are subordinate views over the institutional substrate. | Capital is one track among relationship, capability, claim, rights, authority, evidence, and correction. |
| Essential Attention | Start with one best next action, keep executive questions bounded, block external effects, and make cold handoff executable. | Today view, founder decision queue, effect firewall, progressive disclosure, and cold-successor replay. |
| Clinical Site Fabric | Hash every source, normalize recognized records, preserve unsupported files as source objects, and never infer silently. | Multi-file local intake, SHA-256 receipts, visible parser disposition, and hash-only retention by default. |
| Case Zero | Sensitive material needs credential/PII-shaped holds and body-free or pseudonymized review packets. | Private local intake, public projection, diligence projection, and counsel residue export with source bodies excluded. |
| AXM Witness | Human decisions require tamper-evident history, duplicate refusal, encrypted backup, interrupted-import recovery, and replacement lineage. | Chained receipts, ledger verification, content-hash duplicate refusal, AES-GCM backup, import journal, and append-only corrections. |
| Polybolos | A bounded receipt must not be retroactively rescored when a later test is invented; evidence, outcome, and qualification remain separate. | Immutable public baseline, prospective claim qualification plans, and no-retrospective-upgrade law. |
| Acceptance | A one-file local challenge can be immediately useful with synthetic/public fixtures and zero network dependence. | One-file executable interface, embedded public cartridge, no runtime requests, and built-in stress campaign. |
| Organ Evolution | Do not collapse dimensions into one score; apply hard gates, stress supplier loss, preserve dissent, migration, and succession. | Per-scenario findings, no readiness score, role/authority separation, replacement and succession gates. |
| PTA Tracker | Fail loud or show it, preserve a hostile-source seam, separate facts from human interpretation, and detect gaps instead of drafting narrative. | Runtime health, visible unsupported intake, no automated external copy, explicit missing-state detector, and local human-authored corrections. |
| Breakout Parity | Claims need genealogy, contradiction registers, model revisions, falsification gates, and role-separated exercises. | Claim corrections preserve prior language; stress runs and qualification plans remain explicit and prospective. |
| AXM identity | Frozen releases are not edited; a changed object becomes a new version with provenance. | The public cartridge is immutable, local amendments append, and every export names release and digest. |
| Manzanita Next | Visual continuity without source continuity is a false product; missing credentials or unavailable sources must create receipts, not mock data. | Source custody outranks presentation; unavailable private instruments remain visible unknowns rather than fabricated completeness. |

The convergence test is practical: the tool must remain useful after a year without attention, preserve its public/private boundary, refuse unsupported promotions, recover from local loss through export, and let a successor identify what remains unresolved without interviewing the original architect.
