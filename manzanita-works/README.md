# Manzanita Works Operating Fabric v0.1.0

A public-safe static operating surface that places Essential Tools, Essential Time, pilotage, e-bike mobility, prevention/victim-services workflows, fundraising, stewardship, and replaceable digital systems inside one institutional architecture.

The surface is intentionally broader than a fundraising dashboard. It distinguishes the institutional substrate from the current implementations used to perform bounded functions. Its core question is what Manzanita Works must own so MyTurn, a processor, a fundraising platform, an OSS package, or later hardware can be swapped without erasing organizational identity, authority, projects, accepted events, or continuity.

## Views

- Operating picture: current working estate and controlling questions.
- Projects: program-specific purpose, ownership, commodity layer, and handoff.
- Commons: tools, time, talent, pilotage, money, space, mobility, and knowledge.
- Pilotage: navigation labor and the boundary between assistance and accountable professional authority.
- Money: suggested dues, reasonable rentals, donations, campaigns/grants, and the fundraising dashboard as one projection.
- Commodity perimeter: wrap/adapt/donor/hold decisions and capture risks.
- Architecture: people, legal/authority, information, technology, physical, and money layers.
- Handoff: local review note and portable JSON export.

## Boundaries

This release contains no private member, victim-service, payment, tool-custody, or donor records. It creates no live credits, payments, messages, reservations, commitments, or organizational acceptance. All data are public-safe working descriptions or synthetic operating examples.
