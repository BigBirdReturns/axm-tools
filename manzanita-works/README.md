# Manzanita Works Operating Fabric Dreamboard v0.2.0

The Operating Fabric Dreamboard is a public-safe interactive front door for the common institutional substrate beneath Essential Tools, contribution time, talent, pilotage, mobility, prevention and support, stewardship, and money.

It makes one controlling distinction visible: a fundraising dashboard is a useful projection over institutional identity, purpose, project, restriction, processor, and receipt. It is not the organizational database or authority layer.

## What the page does

- maps twelve familiar program and vendor fragments into eight capacity classes;
- shows seven program organs sharing one institutional substrate without collapsing their different rules;
- separates what Manzanita must own from replaceable inventory, fundraising, payment, scheduling, messaging, open-source, and hardware systems;
- explains the institutional-architecture method through four concrete transformation steps;
- links the public Place & Stewardship and Essential Attention receipts;
- supports direct focused links such as `?focus=fundraising`, local theme persistence, JSON export, print, reduced motion, keyboard operation, mobile, and 320-pixel rendering at 200 percent text.

## Public boundary

The page contains synthetic public-safe architecture only. It has no private member, support-service, payment, custody, credit, or organizational-acceptance records. It performs no external effects and makes no runtime network requests. The public links to existing AXM tools are ordinary user-initiated navigation, not adapters or writeback.

## Qualification

The static contract checks the exact candidate files, release markers, public-safe vocabulary, no-network policy, required capacity classes, program organs, sovereignty rules, proof receipts, and absence of personalized private labels.

The Chromium campaign exercises input-to-capacity highlighting, capacity-to-program projection, program details, the subordinate fundraising lens, architecture and authority explanations, JSON export, theme persistence, deep-link state, keyboard activation, ordinary mobile, 320 pixels at 200 percent text, reduced motion, standalone execution, zero browser errors, and zero unexpected requests.

## What can rot

GitHub Pages, browser support for `color-mix`, Blob downloads, Clipboard API behavior, localStorage, and current Playwright/Chromium installation commands can change. A failure must remain visible. The page must never silently add private data, external-effect adapters, or a vendor-defined canonical record.
