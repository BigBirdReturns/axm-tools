Orientation

What did I just open?

Essential Attention is a role-aware operating cockpit for the aftermath of FAB Meeting #1. It turns scattered events, offers, open questions, and decisions into a source-linked register that can be inspected, tested, and handed off without emailing anyone or turning a named person into the runtime.

What it contains

Loaded on arrival

Seven case objects, five bounded executive decisions, five public-safe source summaries, seven functional seats, a successor packet, an effect firewall, and an append-only local ledger.

What it does

Inside this browser

Inspect evidence and current state, record local draft dispositions, run contained role checks, hash private files locally, test a cold handoff, and export the complete portable packet.

What it cannot do

Outside effects

It cannot send email, schedule meetings, spend money, publish claims, accept offers, appoint people, or represent an organization. Those effects require real authority outside this page.

Where your work lives

Local custody

Drafts, source hashes, run receipts, and replay receipts stay in this browser until you export a packet. The public page contains only the sanitized embedded cartridge.

Recommended route

  1. Use Operations home to select a functional seat and work the attention assistant.
  2. Open Case register in list or process-board mode and inspect all seven guided records.
  3. Open Decision queue, mark all five questions reviewed, and save local drafts only when useful.
  4. Run Run & verify to exercise the seven functional seats.
  5. Use Sources only when you have private evidence worth binding.
  6. Use Activity & export to carry the case elsewhere.
Nothing is assigned by opening this page. Names in the cartridge identify source actors or familiar interface aliases. The operating primitives are functions, needs, evidence, authority, and receipts.
