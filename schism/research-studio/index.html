RUN THE PUBLIC SAMPLE

Take the record with you.

Extract the source ZIP, open its research-studio-0.2.1 folder, and run the command shown here. It creates a fresh local catalog from the included public findings, verifies the source bytes and starts a reader at http://127.0.0.1:8374/. Open that address and select Vendor access to inspect the aggregate and each vendor.

Python 3.11 or newer supplies everything this sample needs. The documentary sample makes no network requests and needs no account. Its verification checks the included file and extracted fields; the linked websites remain the sources for the underlying claims.

Sample instructions ↗ · Reader and source contract ↗

python examples/documentary/run.py

Verify without starting the reader

python examples/documentary/run.py --check-only

Use --output PATH to retain the generated catalog and receipt in a chosen directory. Otherwise they go into a fresh temporary directory.

WHAT THIS RELEASE CONTAINS

A reader, a public ledger and a runnable sample.

The software collects declared local files, binds selected values to their exact bytes, verifies that relationship again and displays research history, findings and separately recorded campaigns. The downloadable package includes the application source, its focused tests and this public documentary fixture. Collection records zero new simulations.
