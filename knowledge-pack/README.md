Public, local-browser reference for opening and verifying portable Genesis knowledge packages. Read exact evidence, inspect signed predecessor history, run actual tamper checks, and obtain the package, source kit, native readers, transport profile, and conformance cases. For existing Obsidian vaults, see VAULT.md for reviewed snapshots, signed successors, and edit-preserving native views.
