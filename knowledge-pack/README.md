# AXM Knowledge Pack and Vault Workbench

Inspect portable signed knowledge in the local-browser verifier, or run the full multi-vault application from the source kit. WORKBENCH.md covers incremental collections, exact source review, selected claim approval, Forge extraction, Spectra retrieval, draft-only watching, native Obsidian views and portable collection verification. VAULT.md retains the smaller round-trip CLI.

Source owner: https://github.com/BigBirdReturns/axm-core/tree/298aaf386cd86f45d04c740be2715bb61e6f8fbf/examples/knowledge-pack

Publication receipt: PUBLICATION.json. Build instructions: REPRODUCE.md. This public directory contains static artifacts only; no private signing key, personal vault or live model endpoint belongs here.
