# AP-410 Kit v2 overlapping Git-blob dispatch data

This unmerged branch is a transport object for the exact 90,028-byte Kit v2 source archive. Five immutable, content-addressed Git blobs retain overlapping source windows created by the original transport. The verifier checks every Git blob identity, reconstructs only through ordered byte overlap, and accepts a result only when the exact sealed byte count and SHA-256 reproduce before internal source authority is inspected.

The branch is not Tools product history, a runtime package, physical evidence, AP-410 acceptance, G3 acceptance, hosted-repository standing, or gate advancement.
