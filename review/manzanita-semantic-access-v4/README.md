# Manzanita semantic access review v4

This review object removes the generic image-gradient trace that had been mislabeled as Access. Access is available only in the Street aperture and only when the exact displayed asset has a semantic feature receipt. Each receipt names visible feature classes, stores separate polygon geometry for the exact source image, states evidence and uncertainty, and preserves explicit non-claims.

The current semantic inventory distinguishes public sidewalk, driveway crossing, private drive or side access, entry path, and entry steps. Occluded or unverified connections are not drawn. Map-only and held states carry no image geometry. Unsupported instruments refuse selection. Shade and Water remain source and field-verification questions and render no image geometry until separately classified semantic receipts exist.

This directory is review evidence. It does not modify the public Manzanita route, authorize a release, create a private record, or grant field, access, safety, work, insurance, enforcement, or adverse-action authority.
