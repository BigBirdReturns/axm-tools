## Anti-goalpost law

A completed result may be revised only by evidence or defects that bear directly on the same completed result:

- source-integrity failure;
- direct contradictory evidence about the same run;
- versioned parser correction;
- versioned evaluator correction;
- demonstrated fixture or execution defect.

A completed result may not be revised merely because of:

- a newly created qualification profile;
- an expanded denominator or gate catalog;
- a stronger synthetic reference campaign;
- an additional optional artifact;
- a later architectural preference or acquisition standard.

A new profile creates a new evaluation. It does not rewrite an earlier receipt.

## Prospective qualification

Every optional qualification plan freezes the following before execution:

```text
plan identifier and version
claim
scope
required artifacts
preconditions
procedure
pass predicates
refusal predicates

explicit exclusions
```

A plan has no authority until it is selected and exported before execution. Each plan is independent. No global `2 of 16` score is permitted for the completed Mark handoff.

## Release profiles

The public release contains a sanitized normalized cartridge, authorized metrics, source roles, and abbreviated source identities. It contains no original private source bytes.

The Mark handoff may contain the original source files because Mark is the source and intended recipient.

A private analyst package may contain original bytes, parser diagnostics, normalization records, and claim crosswalks. Original bytes enter an export only through explicit local opt-in.

Packaging policy is an AXM custody responsibility. It does not change the scenario result.
