# Manzanita semantic instruments review v5

This review extends exact-asset semantic custody beyond Access. Shade now renders only visually classified leaf canopy or seasonal open crown bound to the exact displayed image. Water now renders only visible roof collection surfaces, gutter segments, downspouts, and curb-gutter elements bound to the exact displayed image. Access retains its classified sidewalk, driveway, entry-path, and entry-step inventory.

A scene without a matching semantic receipt carries no image geometry. Map-only and held states carry no image geometry. Neighborhood and regional Shade or Water remain source and verification questions where no exact semantic receipt exists. Care, Heat, Air, Fire, and Assistance remain non-geometric operating surfaces.

This directory is review evidence. It does not modify the public Manzanita route, authorize release, create a private record, or grant field, safety, work, insurance, enforcement, or adverse-action authority.
