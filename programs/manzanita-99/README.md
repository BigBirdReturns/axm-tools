# Manzanita 99-point design rigor program

This program converts the current Manzanita and AXM estate state into a finite, evidence-gated path to a 99-point multidisciplinary design standard. The benchmark is internal. It does not claim endorsement, review, or affiliation by Jen Darhy Bucci, Anduril, or Active Theory.

## Classification

The object is a flagship live-data place instrument and the public front door for a governed AXM estate. It must unify brand, product, mapping, imagery, live sources, evidence, role authority, assistance, continuity, and release operations. It cannot be qualified by a strong hero, a static brochure, a feature count, or a technically valid deployment.

The accountable seat is the design integrator and release authority. Contained review seats cover creative direction, product and interaction, information design, typography, motion, source custody, field operations, accessibility, performance, security, privacy, and successor continuity. No named external person is required to operate or qualify the system.

## The 99-point release rule

A release is admissible only when all P0 tasks are closed, no critical or high defect remains, no applicable gate is unknown, every score dimension is at least 95, the weighted score is at least 99, and both the public-endpoint and cold-successor campaigns pass. The scorecard cannot waive a hard failure.

| Dimension | Weight | Required proof |
|---|---:|---|
| Distinctive identity and memorability | 10 | A sharp outsider can identify Manzanita from an unlabeled crop, motion fragment, control, data plate, or printout without confusing it with another AXM surface or a generic dashboard. |
| Human and mission clarity | 10 | Every state makes the actor, purpose, source, authority, next safe action, and prohibited consequence legible without requiring a manual. |
| Cross-disciplinary system coherence | 9 | Brand, product, imagery, mapping, illustration, motion, copy, data, export, and handoff use one recognizable grammar without becoming repetitive. |
| Typography and optical finish | 9 | Display, editorial, label, data, and compact-width type all pass optical fit, pair spacing, break, rhythm, contrast, zoom, and fallback tests. |
| Visual and material language | 8 | Images, maps, plates, diagrams, textures, lines, icons, and states have intentional hierarchy, source class, and production quality at every scale. |
| Interaction semantics | 10 | Every control changes the underlying operating aperture or state and never substitutes a label change for a functional change. |
| Motion and temporal continuity | 7 | Motion explains scale, source change, registration, state transition, or handoff; reduced motion preserves all meaning. |
| Live data, source custody, and degradation | 10 | Every live or derived claim exposes source, time, transform, uncertainty, rights, cache rule, health, and failure state. |
| Responsive and accessible operation | 8 | Desktop, laptop, tablet, mobile, compact, keyboard, touch, screen reader, 200 percent zoom, and reduced motion preserve the same hierarchy and actions. |
| Performance and resilience | 7 | The product meets defined budgets on realistic devices and remains useful under slow, intermittent, offline, stale, and provider-outage conditions. |
| Fit, finish, and perceptual QA | 8 | No visible clipping, loose spacing, weak crop, underdrawn state, generic placeholder, accidental default, or unresolved edge survives release review. |
| Continuity, privacy, and release governance | 4 | Public and private projections, rights, purpose limits, exports, rollback, receipts, and cold-successor replay are complete and independently verifiable. |

## Task completion law

A task is not complete when code exists. It is complete when the intended actor can use the object, the source or authorship custody is retained, the claim boundary is visible, the fallback or failure state is exercised, responsive and accessible behavior is proved, and the result survives the applicable contained review seats. Any task that changes a public visual or interaction requires full-state goldens rather than selected crops.
