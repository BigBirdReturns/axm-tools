The stack already exists

A sovereign enterprise system needs hardware admission, a model runtime, verifiable knowledge artifacts, organizational authority and meaningful acceptance evidence. These are distinct interfaces, with existing open implementations.

01 · Cryptographic truth

AXM Genesis, Forge, Spectra and Clarion preserve source identity, verified records, queryability and transport. Every accepted release has an independently verifiable origin.

02 · Placement and workload

AXM Zombie Adapter plans physical GPU placement; existing Estate/TierDesk semantics maintain bounded work and recovery. GPUs are individually accountable, never magically pooled.

03 · Shared inference

vLLM keeps the base resident and supports many pinned LoRA adapters. The host-local controller admits only authorized exact files and measures real activation.

04 · Residency and authority

Every region runs under the enterprise's own physical, storage and network jurisdiction. CAIRN/APERTURE policy concepts guide the admission model; IAM and egress control must be real.

05 · Evidence and measurement

Cantos records cost, workload qualification and observed outcomes. Signed source evidence is kept distinct from projections or benchmark advertising.

06 · Durable evolution

Every release has a pinned identity, an acceptance gate and a revocation path. The enterprise keeps its artifacts and may replace the execution engine without surrendering records.

Use the real software

Run the installed independent Genesis verifier, launch a private vLLM base, stage a sealed adapter and activate it with explicit authority. The example registry is a template requiring actual hashes and files.

# 1. Private node-local base, version-pinned
export VLLM_ALLOW_RUNTIME_LORA_UPDATING=True
vllm serve /srv/models/pinned-base --served-model-name demo-base \
  --host 127.0.0.1 --port 18406 --enable-lora --max-loras 8

# 2. Exact, signature-backed admission
python3 sovereign.py --registry /etc/sovereign/registry.json \
  --ledger /var/lib/sovereign/admissions.jsonl \
  --trusted-key /etc/sovereign/genesis-public.key \
  activate --tenant plant-a --adapter quality --region us-west

# 3. Verify the independent outcome log
python3 sovereign.py --ledger /var/lib/sovereign/admissions.jsonl verify-ledger
Security boundary: The administrator endpoint remains loopback-only. A customer-controlled IAM gateway owns public inference requests; this controller never exposes dynamic LoRA loading to untrusted callers.
