# AXM Witness Department Ledger 0.9.0

## Classification

`qualified local department-controlled export ledger pilot`

This is the first release whose stated operational result supports a controlled department-owned pilot. A department may open the application on department-controlled hardware, initialize its own ledger, import authorized Flock-shaped exports, preserve exact source files, review activity, record human decisions, verify the resulting chain, export an encrypted full-ledger backup, restore it in a clean browser profile, and continue writing under the same department signing identity.

This release does not establish PSPD employment standing, municipal SSO, an approved retention schedule, administrator-controlled role provisioning, a city key ceremony, a live Flock acquisition contract, or upstream declared-stream completeness.

## Admitted release claims supplied by the release packet

- A realistic Flock Organization Audit is recognized directly.
- `Name` maps to the searching user.
- `Case #` maps to the case reference.
- `Search Time` maps to event time.
- `Search Type` remains a property of a search record rather than being mistaken for the event family.
- Exact source bytes, normalized packets, packet order, action rationale, actor, local role, review state, finding state, and final disposition share one signed state commitment.
- Direct source-byte, rationale, or review-state alteration changes verification to `FAIL`.
- Full continuity packages are encrypted with PBKDF2-SHA256-derived AES-256-GCM and contain the object store, exact source files, reviews, findings, actions, packet chains, receipts, and department signing key.
- Clean-profile restoration verifies before import, restores the signing identity and ledger head, appends a signed restoration record, and continues the chain.
- Large admissions checkpoint every 100 rows and can resume after interruption.
- The qualification intentionally interrupted a 2,000-row Organization Audit after 500 rows, resumed from retained source bytes, admitted all 2,000 records, and completed inside the 30-second qualification ceiling.
- Exact duplicate imports are refused.
- Replacement exports become successor source versions under the same review; previous sources remain retained and prior findings become superseded rather than deleted.

## Qualification denominator

The supplied release report records `37 / 37` direct controls passed, covering native Organization Audit semantics, complete row admission, exact-source and packet-chain verification, signed decision continuity, IndexedDB tamper detection, encrypted backup confidentiality, clean-profile same-key continuation, interrupted 2,000-row recovery, duplicate refusal, replacement lineage, privacy-safe city receipts, nonempty downloads, zero runtime network requests, zero browser errors, mobile reflow and target sizing, source ZIP and Git-bundle reconstruction, and package CRC and checksum replay.

## Exact operating boundary

The department can own custody and the decision ledger for Flock records it receives. The release does not prove that Flock delivered every upstream record. Stable vendor cursors, high-water marks, or signed inventories remain necessary for declared-stream completeness. A city-controlled edge or independent delivery path remains necessary for origin-level detection of silent pre-delivery omission.
