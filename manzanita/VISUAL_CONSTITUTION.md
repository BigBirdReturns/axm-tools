# Manzanita Works Signal Sheet visual constitution

Release family: `manzanita-works/signal-sheet@1`

The interface is an analytical place record. It uses the AXM Signal Sheet grammar to make the current object, evidence class, authority boundary, safe action, and handoff visible without converting the work into a KPI dashboard or a lifestyle brand.

## Field law

Light mode uses a warm editorial sheet, analytical black ink, hairline rules, and one consequence orange. Dark mode is the same grammar inverted. The toggle changes field and ink, preserves hierarchy and geometry, persists locally, and begins from system preference only when no local choice exists.

No section may introduce a decorative gradient, glass blur, floating card shadow, rounded dashboard tile, or unbounded accent palette. Field changes must correspond to a semantic transition: ordinary analytical sheet, inverse custody sheet, or signal consequence band.

## Type law

Display type is large, heavy, left aligned, tightly tracked, and limited to the controlling proposition. Supporting prose remains subordinate. Uppercase monospaced labels identify object class, sequence, provenance, state, and authority. A heading may be quiet, but it may not be vague.

## Rule law

Hairlines, ledgers, and whitespace group related objects. Boxes exist only when a boundary has semantic meaning. Cards may not replace document structure. Repetition must use shared alignment, rule weight, label position, and number grammar.

## Visual-object law

The visual atlas uses crisp estate-owned vector scenes. Each scene states its evidence class and claim boundary. Overlays reveal independent conditions and follow visible or modeled edges. They cannot collapse a household into one score or convert illustration into survey, inspection, ownership, enforcement, or completed-work authority.

## Interaction law

The primary operating route is visible without onboarding machinery:

```text
Plant → Household → Property → Street → Neighborhood → Region → Stewardship
```

Every scale exposes the current reading, what matters, next safe action, and authority boundary. Eight overlays and five functional perspectives remain independently selectable. The theme toggle, scale rail, overlays, roles, and Essential Attention handoff are keyboard accessible and retain conventional browser behavior.

## Release law

A release fails when the public endpoint loses the exact release marker, the theme toggle does not persist, any scale or role becomes unreachable, the page overflows at the qualified mobile width, a browser error occurs, an unexpected external request occurs, the visual constitution is violated, or the public endpoint differs from the qualified branch behavior.
