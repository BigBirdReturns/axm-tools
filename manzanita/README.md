# Manzanita Works v1.1.2

A public-safe photographic front door for the connected Household Habitat, Street Glide, Regional Observatory, Civic Planner, Manzanita Works, and Essential Attention estate.

The page is static and local-first. It contains seven scales, eight independent overlays, five functional perspectives, an assistance-first operating sequence, an explicit purpose firewall, and a direct handoff into Essential Attention. It has no backend and no external-effect adapters.

The photographs are coordinated Southern California reference views. They are not registered evidence of one surveyed property. Overlays are explanatory guides rather than measured parcel or hazard determinations.
