# Manzanita Works v1.1.2

Public-safe household-to-region front door connecting Household Habitat, Street Glide, the Regional Observatory, Civic Planner, Manzanita Works, and Essential Attention. The four embedded images are coordinated generated reference views, not registered evidence of one surveyed property. No private records or external-effect adapters are present.

Live surface: <https://bigbirdreturns.github.io/axm-tools/manzanita/>

The release is qualified on its branch and pull request, deployed by the repository's existing Pages workflow, and then tested again against the public endpoint by `manzanita-live-check.yml`.
