The object is a source-bound operating experience over one canonical place. The design integrator owns coherence across sections, transitions, help, failure states, outputs, viewports, and themes. Controls change the governed operating object. They do not merely relabel one static screen.

## Mechanism

`build_experience.py` consumes the exact public dossier and projection receipt, seven-aperture bundle, Street Glide scene and registration receipts, eight-overlay bundle, five-role bundle, FAB handoff, all donor build receipts, the Forkline Field constitution, the base-image bytes, and the experience contract. It proves one place and source-run identity, checks donor effects, rejects private and credential fields, preserves degraded and authored evidence, binds the overlay geometry to the exact base image, and emits a deterministic experience dossier, local site, and build receipt.

The static site is self-contained and makes no network request. Aperture controls change object, evidence, action, and authority. Overlay controls change source state, geometry, legend, uncertainty, conflict, and consequence. Role controls change controls, authority, acceptance, export, handoff, and failure state. Auto, Light, and Dark preserve one information hierarchy. Help remains available after orientation. Export produces a local JSON snapshot and no external effect.

## Operation

After rebuilding the upstream donors:

```bash
python manzanita-next/experience/build_experience.py \
  --repo-root . \
  --public-demo-root manzanita-next/public-demo/out \
  --aperture-root manzanita-next/apertures/out \
  --street-glide-root manzanita-next/street-glide/out \
  --overlay-root manzanita-next/overlays/out \
  --role-root manzanita-next/roles/out \
  --output manzanita-next/experience/out
```

Run the static and browser campaigns:

```bash
python -m unittest discover \
  -s manzanita-next/experience/tests \
  -p "test_experience.py"

python manzanita-next/experience/tests/browser_test.py \
  --site manzanita-next/experience/out/site \
  --output manzanita-next/experience/out/browser
```
