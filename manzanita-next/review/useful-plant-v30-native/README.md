# Useful Plant v30 repository-native review

This directory is a bounded, repository-native continuation of the Useful Plant v30 review work. It converts the aperture into inspectable HTML, CSS, JavaScript, contract, source verifier, and browser campaign rather than asking a reviewer to trust an opaque rendered binary or a transport-only payload.

The surface begins with the admitted photographic Plant asset already present at `manzanita/assets/plant.webp`. Registered geometry, modes, operating seats, evidence tiers, household stop controls, the six-stage use loop, and the seven visual-admission questions are implemented as reviewable source. The workflow measures the donor in place, verifies that every changed path remains inside this review object, exercises desktop, mobile, 200-percent-text, seat, zone, evidence, URL-state, and stop-authority behavior, and retains the screenshots and receipts as an Actions artifact.

## Authority boundary

This object has no adapter for deployment, insurance denial, unrelated property scoring, resident ranking, punitive enforcement, or any other external action. It does not modify `manzanita/`, root entry points, or GitHub Pages. It does not authorize merge or release. The admitted public Plant photograph is used as a repository donor and is not relabeled as the missing exact v29 Plant object.

Operator visual acceptance remains `ABSENT`. Acceptance must be recorded outside the candidate after inspection of the retained browser evidence.
