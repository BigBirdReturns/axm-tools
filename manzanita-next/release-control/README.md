# Manzanita release control and continuity

This package creates the first byte-addressed internal release candidate from
the admitted Manzanita source, whole-experience, automated qualification, and
estate-parity chain. It packages the exact generated P7 site, the historical
public `manzanita/` route as rollback donor, and the controlling P7, P8, and P9
receipts into one deterministic portable archive.

The release authority owns public promotion. The continuity seat owns archive,
reimport, served-byte, rollback, and successor receipts. The qualification
operator may observe the exact internal candidate. External campaign operators
own real assistive-technology, human, device, network, private, provider, field,
archive, public-endpoint, and deployed-rollback evidence. No seat may borrow
another seat's result.

`replay_p9_workflow.py` extracts only the exact estate audit, P7 and P8 rebuild,
P9 build, and P9 contained-review run blocks from the admitted workflow. It
imports no merge, publication, deployment, score, or external-effect authority.

`build_release_control.py` performs the bounded local continuity campaign. It:

- verifies the P7, nineteen-campaign P8, and complete-coverage P9 receipts;
- rejects private and credential keys, public effects, failed campaigns, open
  vetoes, critical or high defects, uncovered surfaces, and unknown components;
- copies the exact candidate and historical rollback donor;
- hashes every candidate, rollback, and evidence file;
- builds a deterministic ZIP with fixed metadata and no unsafe paths;
- extracts and reimports the archive;
- runs a standard-library verifier under isolated Python with no repository
  imports or private credentials;
- serves and rehashes every candidate and rollback byte over loopback HTTP;
- performs an atomic local directory-swap rollback that ends on the historical
  donor;
- emits manifest, decision, continuity, and build receipts.

The release decision remains `HOLD` while any required external campaign is
unperformed or lacks its own accountable evidence. Even an all-campaigns-passed
ledger can advance only to `READY_FOR_PUBLIC_RELEASE_REVIEW`; this package never
self-authorizes publication.

Loopback serving is not public-endpoint proof. Same-runner isolated verification
is not an independently controlled successor, machine, account, or archive.
Local directory swapping is not a deployed rollback. The historical route is
copied and verified as a rollback donor but is not modified or redeployed by
this package.

The controlling question is whether a cold successor can recover, verify,
serve, export, reimport, explain, and locally roll back the exact candidate from
retained bytes while release authority still refuses public promotion until
every external campaign carries its own accountable receipt.
