# Breakout Parity Demonstrator

A zero-network synthetic tabletop for testing whether bounded institutions can preserve a conservative margin to coercive advantage under rolling threats, decoys, disputed evidence, restoration obligations, and N-1 failure.

## Run

Open `index.html`. No server, login, API key, network connection, external JavaScript, or production data is required.

## Retained scenarios

| Scenario | Required result |
| --- | --- |
| BP-QE-001 Qualified entry | Operate after N-1 flex, decoy resolution, rollback, cure, restoration, and recertification |
| BP-HO-002 Hidden holdout | Reveal the uncovered lineage and declare HOLD |
| BP-N1-003 Ambiguous event | Preserve role separation, record dissent, clear decoys, control and restore the real case, and pass N-1 |
| BP-SAT-004 Saturation | Hold before optimistic continuation or indiscriminate action |

The authority-failure path deliberately attempts actions from the wrong seats. Those attempts must be rejected, logged, and excluded from valid state transitions.

## Files

- `index.html`: standalone exercise and receipt exporter.
- `EXERCISE_PROTOCOL.md`: ninety-minute exercise protocol and gate.
- `ROLE_CARDS.md`: seven bounded institutional seats.
- `ACCEPTANCE_TESTS.md`: twelve qualification tests.
- `FIELD_DATA_REQUEST.md`: non-sensitive measurements needed for a real exercise.
- `SOURCE_LEDGER_V11.csv`: public institutional precedents informing the role boundaries.

## Evidence boundary

The scenarios are synthetic and contain no weapon-design information. The roles are functional analogues informed by public practice. The demonstrator is not affiliated with or endorsed by the IAEA, CTBTO, HCoC, IPNDV, UNIDIR, any government, or any nuclear operator. Timing, risk, confidence, and capacity values are test variables rather than empirical estimates.
