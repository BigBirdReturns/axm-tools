# Bounded External Review Request

## Object

A ninety-minute synthetic, offline demonstrator of a rolling-threat control architecture. It tests role boundaries, finite queues, N-1 failure, decoys, dissent, rollback, restoration, and an adverse-bound hold gate.

## Requested review

Please identify:

1. Which role or interface conflicts with established authority or practice?
2. Which handoff omits a necessary evidentiary, legal, safety, security, or political step?
3. Which synthetic action creates an unrealistic timing or capacity assumption?
4. Which scenario should fail but currently passes, or pass but currently fails?
5. Which institution or research programme should own a measured version of that interface?

A rejection, prior-art correction, or narrower scope is a successful review output. Receipt or participation will not be represented as endorsement.
