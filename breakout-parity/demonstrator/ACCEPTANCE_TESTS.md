# V11 Acceptance Tests

## AT-01 Offline integrity

The demonstrator loads and operates without an external network request, external script, remote font, API key, login, or production credential.

## AT-02 Qualified entry

The reference path for `BP-QE-001` must end in `OPERATE`, with no known holdout, N-1 pass, no breach, and on-time restoration.

## AT-03 Hidden holdout

The reference path for `BP-HO-002` must reveal at least one uncovered lineage and end in `HOLD` or `BASELINE INCOMPLETE`. No downstream action may convert it into a pass.

## AT-04 N-1 and ambiguity

The reference path for `BP-N1-003` must survive the declared critical-node loss, clear both decoys, preserve dissent, control the real case, restore benefits, and pass recertification.

## AT-05 Saturation

The reference path for `BP-SAT-004` must hold while portfolio load exceeds the certified boundary. The system must not claim successful operation because no individual case has yet breached.

## AT-06 Authority separation

An action submitted from the wrong role must be rejected, logged, and absent from the target object's valid state-transition history.

## AT-07 Finding preconditions

A significant-anomaly finding requires sufficient confidence and an access record. A consequence requires a qualifying finding.

## AT-08 False-positive correction

A decoy subjected to managed access, synthetic sampling, and review must resolve to no concern without rollback or punishment.

## AT-09 Restoration symmetry

A controlled real case cannot receive restored benefits until cure is verified. Once verified, restoration must be executable through an objective action rather than a new political negotiation.

## AT-10 Receipt integrity

The receipt must identify protocol, schema, scenario, actions, role rejections, threat lineage, N-1 state, gate metrics, evidence boundary, and a canonical SHA-256 digest.

## AT-11 No weapon-design detail

The package must contain no operational design, construction, production, triggering, yield, targeting, or evasion instructions. Threat clocks and activities remain abstract.

## AT-12 Honest inference

The public and operator documentation must state that passing a synthetic scenario does not establish empirical performance, legal authority, or institutional endorsement.
