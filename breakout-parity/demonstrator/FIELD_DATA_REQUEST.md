# Field Data Request for a Real Demonstrator

The next validation stage does not require classified programme details or weapon-design information. It requires measured institutional throughput and failure behavior.

## Requested non-sensitive measurements

| Interface | Measurement |
| --- | --- |
| Alert to analyst acknowledgement | Distribution of elapsed time under normal and surge conditions |
| Analyst acknowledgement to initial characterization | Median and adverse-tail elapsed time; rework rate |
| Evidence packet assembly | Time, missing-provenance rate, and number of incompatible formats |
| Managed-access negotiation | Time to agreed scope, denial rate, and unresolved access conditions |
| Inspection execution | Team preparation, field duration, chain-of-custody exceptions, and reporting time |
| Laboratory queue | Normal, surge, and N-1 turnaround distributions |
| Technical adjudication | Time to finding, dissent frequency, appeal frequency, and unresolved-case rate |
| Reversible response activation | Legal and administrative activation time by measure type |
| Defensive reinforcement | Time from request to observable protective effect |
| Rollback offer | Time to issue terms, accept, preserve evidence, and begin cure |
| Cure verification | Time, failed-verification rate, and repeat-access demand |
| Restoration | Time from verified cure to actual benefit restoration; political override frequency |
| Critical-node loss | Capacity lost, reserve activation time, and recovery profile |
| Decoy load | False-positive volume, capacity consumed, and false-action rate |
| Gate decay | Time between qualification and material change requiring recertification |

## Minimum real exercise

A real demonstrator should use synthetic or sanitized data and include:

- three heterogeneous real cases;
- two plausible decoys;
- one disputed interpretation;
- one failed inspection, laboratory, or analysis node;
- one supplier or service interruption;
- one corrective rollback and restoration obligation;
- one deliberately attempted authority overreach;
- one independent observer and one external evaluator.

## Success criterion

The exercise succeeds as research when it produces an honest measured interface ledger, including failed timelines and unavailable authorities. It need not endorse the architecture or pass the operating gate.
